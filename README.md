# حلال تريدير — السوق الأمريكي

برنامج تداول إسلامي ذكي يعمل **تلقائياً بدون تدخل**.

## ما تم إنجازه (المراحل 1 + 2 + 3)

- واجهة عربية كاملة (PWA قابل للتثبيت)
- توقيت دبي + نيويورك + حالة السوق
- قائمة أسهم شرعية نواة قوية
- تحليل أخبار ديناميكي + توصيات بدون نسب ثابتة
- سجل تفصيلي + تصدير CSV + إحصائيات
- دعم Finnhub المجاني
- إشعارات Push
- Cloudflare Worker مع Cron للتشغيل التلقائي قبل السوق
- تعليمات نشر كاملة في `DEPLOY.md`

## كيف تستخدمه

1. اقرأ **`DEPLOY.md`** واتبع الخطوات.
2. انشر الواجهة على Cloudflare Pages.
3. انشر الـ Worker وأضف المفاتيح.
4. من الجوال: ثبّت التطبيق → فعّل الإشعارات.

بعدها كل شيء يعمل لوحده.
